# Sistema Bancário em Python

## Descrição

Sistema bancário simples desenvolvido em Python como atividade de programação.

O sistema permite realizar:

- Depósitos
- Saques
- Consulta de extrato
- Encerramento do sistema

## Regras

- Saldo inicial: R$ 0,00
- Limite por saque: R$ 500,00
- Máximo de 3 saques por dia
- Depósitos e saques devem possuir valores maiores que zero

## Tecnologias utilizadas

- Python
- GitHub
- VScode
